Two of the three builds in [What survived the classroom](/edubuilds/) started with a version of this prompt: the Oregon Trail-style Gold Rush game for a San Francisco 1849 unit, and the organizers for a place-based water project. Both began as one page.

## Spec first, then the interactive version

The Gold Rush case teaches an order. Ask for a one-page spec first: the setting from the source, three choices, the consequence of each tied to a source fact, one invented rule labeled as invented, one question that requires evidence. Review the spec. Only then ask for the interactive version, if you want one. A game built straight from a prompt has rules nobody checked.

## The decision activity template

For a manageable version of a bigger build, one page with these fields: the learning goal, the source facts, the learner choice, the consequence, the explanation question, and one likely misconception. Fill the facts from the source. Label the rest as yours.

## What to check before you use it

- Which information comes from the source, and which rule was invented for play. They stay visibly separate.
- What a learner might mistakenly take as history or science. Fix the framing, not just the fact.
- Whose perspectives are in the cast, and who is missing.
- Whether the decisions you listed actually stayed with learners. If the organizer answers its own questions, send it back.

## What went wrong the first time

The generated biography pages behind the Gold Rush game needed debugging by hand, and every scavenger-hunt question had to be checked against the biography text so the answer was findable without being obvious. Budget the checking time. It is most of the build.

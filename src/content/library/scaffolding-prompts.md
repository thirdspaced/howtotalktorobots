Scaffolds are where an AI draft most often ends up doing the learner's work. These six prompts are short on purpose, so an answer sneaking in is easy to spot. The first is above and the other five are below. Copy the one you need.

## Sentence frames that point to the text

```
Give me three sentence frames that require the learner to use the term [term] and point to a line in the text. Do not include a completed example.
```

## Pre-teach cards

```
Pre-teach cards for these five terms: a plain definition under ten words, one example sentence taken from the source, and one picture I could draw or find. No facts from outside the source.

Terms: [list]
Source: [paste]
```

## Chunk a passage with a question after each chunk

```
Split this passage into chunks of no more than [60] words. After each chunk, write one question a learner answers before moving on. Do not add facts and do not summarize the chunk for them.

Passage: [paste]
```

## A half-filled organizer, both ways

```
Build a [cause and effect] organizer for this text with the causes filled in and the effects left blank, and a second copy with the effects filled in and the causes blank.

Text: [paste]
```

## Fade the support

```
Make a faded version of this organizer: same structure, two fewer prompts, for a learner who has completed the full version twice. Tell me which prompts you removed and why.

Organizer: [paste]
```

## What to check before you use any of them

- The thinking is still the learner's. If a frame, a card or an organizer contains the answer, send it back.
- Every example sentence and every fact traces to the source you gave.
- The scaffold isn't harder to read than the text it supports.

These come from the reading-access build in [What survived the classroom](/edubuilds/). The test for each one is whether you can say exactly what the learner still has to do.
